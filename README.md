# Customer_Churn_Analysis_Python

This project analyzes customer data to understand churn, retention, and customer behavior.

**Tools:** Python, Pandas, NumPy, SQLite, Matplotlib, Seaborn

I cleaned and combined the customer, subscription, and support data, then performed analysis to identify churn patterns and customers at risk.

**Key finding:** The overall churn rate was **28.57%**, with the Basic plan showing the highest churn.
